# E0302 — Use after transfer

An owned value was moved into another place (assignment, function call, or return) and then used again.

## Example

```buraaq
fn main() {
    give connection = open()
    send_request(connection)
    connection.close()  // E0302
}
```

## Why

Buraaq enforces single ownership for non-`copy` types. When you pass `connection` to `send_request`, ownership transfers to the callee.

## Fix

If the callee only needs temporary access, borrow instead:

```buraaq
send_request(ref connection)
```

Or restructure so the value is not used after the transfer.
